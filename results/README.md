# Results

Analysis outputs are generated locally and are not tracked in Git. Compact
source data supporting the manuscript tables and Figures 2-7 are distributed
through the associated Zenodo dataset
([10.5281/zenodo.22140383](https://doi.org/10.5281/zenodo.22140383)).

After extracting the archive, use the following paths:

```text
random_forest/summaries/
  -> results/random_forest/summaries/

convlstm/summary_metrics.csv
convlstm/area_summary.csv
  -> results/convlstm/

convlstm/prediction_frequency/
  -> results/convlstm/figure5_source/

convlstm/robustness/
  -> results/convlstm/robustness/
```

The RF and ConvLSTM workflows can also regenerate these outputs. Model
checkpoints, full repeated-run files, and intermediate arrays remain local.

`results/figures/Fig1.png` is retained because the Figure 1 subpanels were
assembled manually. Other figure files are regenerated by the scripts under
`code/figures/` and remain untracked.
